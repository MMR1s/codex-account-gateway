# Record a dashboard walkthrough

Use a recorder with cursor smoothing, custom pointer styles, and automatic zooms. FocuSee and CANVID support Windows; Screen Studio supports macOS. Record the browser window, then adjust cursor size and zoom timing in the editor.

| Time | Action | Caption |
| --- | --- | --- |
| 0–5s | Overview: let the constellation animate and drag it gently. | One workspace. Every account. |
| 5–15s | Accounts: show routing state, five-hour and weekly allowance, and reset times. | Separate sign-ins. Separate allowance. |
| 15–20s | Choose another available account with **Use this account**; show its Routing badge. | Choose the account for new requests. |
| 20–30s | Overview: select Agents, inspect a thread, and follow its recorded parent/child relationships. | Agents and subagents, in one view. |
| 30–40s | Overview: scroll to token distribution, throughput, and allowance history. | Visibility into gateway traffic. |
| 40–45s | Traffic: follow one row from account to tokens, duration, and outcome. | Trace each captured request. |
| 45–50s | Return to Overview. | github.com/MMR1s/codex-account-gateway |

Move deliberately and pause briefly after clicks. Keep account identities hidden and blur private task titles. Do not record sign-in screens, device codes, credentials, or configuration backups.

Request lights indicate inference requests currently passing through the gateway. Capture a real gateway request if you want the lights in the video. Tools, waiting, and direct-provider chats are unobserved. Label any staged activity as a demonstration.

Token totals cover gateway traffic only. Account credentials and quotas remain separate; local files and workspace stay in place. The project does not merge account histories or provide a phone-connection feature. SSH is configured separately.
