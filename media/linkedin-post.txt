I built Codex Relay — a local control room for my Codex workspace — and made it open source.

The idea: keep my chats, files, and projects in one place while routing model requests through a pool of separately signed-in accounts.

The dashboard brings together:
• Manual account switching
• Five-hour and weekly allowance, remaining percentages, and reset times
• A spatial view of recorded agents and their subagents, with lights for observed gateway requests
• Token usage, request timing, outcomes, and charts
• Automatic failover on recognized usage limits before output starts

Each account keeps its own credentials and allowance. The gateway records request metadata, not conversation text, and token totals cover traffic passing through it.

For remote work, use SSH to the machine running Codex and the gateway. The workspace stays on that machine; SSH is configured separately.

Built with Python, FastAPI, and LiteLLM OAuth helpers. Windows setup included. MIT licensed.

This is an independent experiment, and backend compatibility can change. Account-bound compacted context can still require the original account.
